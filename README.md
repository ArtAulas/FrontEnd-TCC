# FrontEnd Projeto TCC
# Rede Social para Participação Política

Esse repositório contém o FrontEnd que usa o projeto [BackEnd-TCC](https://github.com/ArtAulas/BackEnd-TCC).

O projeto é desenvolvimento em TypeScript, utilizando o React com Vite para desenvolvimento da estrutura.

Para a estilização da plataforma, foram utilizados o Shadcn e Tailwind, visando manter uma aparência profissional.

As variáveis de ambiente estão listadas no arquivo **.env.sample**
